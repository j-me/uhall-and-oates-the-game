# Local soundtrack overrides

Files in this directory are intentionally excluded from Git, except for this
README. The game checks here first, then falls back to the original,
repository-safe music in `../music/`.

Expected optional filenames:

- `title.mp3`
- `chapter-01.mp3`
- `chapter-02.mp3`
- `chapter-03.mp3`
- `chapter-04.mp3`
- `chapter-05.mp3`
- `chapter-06.mp3`
- `outro.mp3`
